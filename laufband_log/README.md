# Laufband-Log

Zeichnet Walking-Pad-Workouts auf, zeigt sie mit Verlaufsdiagrammen an und steuert das Band.
Erscheint nach dem Start als **Laufband** in der Seitenleiste.

Im Tab *Protokoll* sollte stehen: `Mit Home Assistant verbunden, 6 Entitäten abonniert`.

**Update:** neue Version auf GitHub pushen (`version` in `config.yaml` erhöhen),
dann *App Store → ⋮ → Nach Updates suchen → Aktualisieren*. Workouts bleiben erhalten.
